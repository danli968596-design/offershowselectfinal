OfferShow UI 确认版 · 2026-10-15

把这个 ZIP 整包解压后再打开，不要只取出一个 HTML 文件。

快速看 UI：用 Chrome 或 Edge 打开 index.html。
首次从首页开始为空白数据，不会自动填入上次选择或演示答案。Offer 录入页仍可点击“示例数据”，示例公司为 OfferShow1、OfferShow2、OfferShow3。
从首页依次查看：偏好画像 → 填写 Offer → 分析结果 → AI 背调。

完整交互预览（推荐，尤其是分享图片下载）：
Mac：双击“启动预览.command”；或在本目录终端运行 python3 启动预览.py。
Windows：双击“启动预览.bat”；或在本目录运行 py 启动预览.py。
需要安装 Python 3。启动脚本会用 /ui/index.html 作为稳定预览入口，同时提供上一层项目中的原算法模块；启动后会自动打开本地浏览器，关闭终端或按 Ctrl+C 停止。
使用空闲的本机端口，不需要修改现有 8776 预览服务。

浏览器可能限制 file:// 页面之间的数据共享或 Canvas 图片下载；遇到限制时请使用上述本地启动方式。
这是可编辑的静态 UI 原型；AI、会员支付和小程序目标页面尚未接入。
开发接入事项见“开发交接.txt”。
